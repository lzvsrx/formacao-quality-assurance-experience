# Criando Testes Automatizados de UI em Android com Kotlin e Espresso

O projeto Android Kotlin/Espresso funcional de referência já está em `../06-mobile/android/` e foi preservado nesta atualização. Esta pasta registra os cenários de entrega e as instruções para execução.

1. Abra `06-mobile/android` no Android Studio.
2. Sincronize Gradle e selecione um emulador Android.
3. Execute `connectedAndroidTest` ou rode `MainActivityTest` pelo Android Studio.
4. Registre evidências reais em `evidencias/` (não incluídas como se tivessem sido executadas).

Cenários-alvo: abertura da tela, preenchimento, validação de formulário e feedback ao usuário. Consulte o teste existente para identificar as asserções efetivamente implementadas.
