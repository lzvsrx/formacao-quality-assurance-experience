# Desenvolvimento de Testes Unitários para Validar uma API REST de Gerenciamento de Estoques de Cerveja

Projeto original inspirado no escopo público do desafio: Spring Boot, JUnit, Mockito, MockMvc, cadastro, consulta, listagem, exclusão, incremento e decremento. Implementação em memória para facilitar execução local (não reproduz o repositório original das aulas).

Requisitos: JDK 17+, Maven 3.9+. `mvn test` e `mvn spring-boot:run`.

Exemplo: `POST /api/beers` com `{"name":"IPA","brand":"Marca","quantity":5,"max":20}`.
