# Técnicas de projeto
- Partição de equivalência: idade inválida < 18 e válida >= 18.
- Valor limite: 17, 18 e 19.
- Tabela de decisão: cliente ativo/inativo × pagamento aprovado/reprovado.
- Transição de estado: pedido criado -> pago -> enviado -> entregue; cancelamento somente antes do envio.
- Teste exploratório: charters com duração, riscos, observações e defeitos.
