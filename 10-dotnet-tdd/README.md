# Desafio TDD — cadastro e validação
Implementação original de cadastro em memória com xUnit: cenários válidos, inválidos, duplicidade e remoção. Requer .NET SDK 8+. Execute `dotnet test Cadastro.Tests/Cadastro.Tests.csproj`. Para praticar TDD, escreva primeiro um teste que falha, implemente o mínimo e refatore.
