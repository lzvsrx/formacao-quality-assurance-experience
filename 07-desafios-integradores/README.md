# Desafios integradores — originais para portfólio
1. **QA manual**: plano, matriz de rastreabilidade, 5 casos e 2 relatos de defeito de um e-commerce fictício.
2. **TDD**: calculadora de descontos com JUnit, cobrindo limites e entradas inválidas.
3. **API**: validar status, payload, erros e contratos da API Node existente.
4. **Front-end**: testar validação, acessibilidade e fluxo ponta a ponta com Playwright.
5. **Mobile**: executar teste Espresso de tela e documentar evidências.
6. **CI**: configurar workflow para testar Java, Node, .NET e front-end; revisar logs.
Critério de conclusão: código, testes, comandos reproduzíveis e evidências sem dados pessoais.
