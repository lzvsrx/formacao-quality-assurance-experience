# TDD: Entendendo e Praticando em um Backend com Node e TypeScript

Projeto original de API REST de tarefas com Vitest e Supertest. Ciclo sugerido: RED (escrever teste que falha), GREEN (implementação mínima), REFACTOR (melhorar design sem alterar comportamento).

```bash
npm install
npm test
npm run dev
```

Rotas: GET /tasks, POST /tasks, PATCH /tasks/:id/complete, DELETE /tasks/:id.
