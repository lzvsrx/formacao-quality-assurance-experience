# Desafios de front-end
1. Validar formulário por teclado (Tab, Enter, Shift+Tab).
2. Conferir rótulos acessíveis e mensagens de erro.
3. Criar teste E2E para envio válido e inválido.
4. Verificar layouts mobile e desktop; registrar resultados.
5. Executar `npm test` e `npx playwright test` após instalar dependências e navegadores.
