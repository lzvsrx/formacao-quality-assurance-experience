**Status:** implementações originais correspondentes aos temas informados, não cópias de código das aulas. Não foi possível auditar a lista completa de arquivos de cada aula em área autenticada. Não alegamos execução de testes ou equivalência literal com os entregáveis oficiais.

## Executar
- Java: `cd 14-desafio-beerstock && mvn test`
- Node: `cd 15-desafio-node-tdd && npm install && npm test`
- .NET: `cd 16-desafio-dotnet-tdd/Conta.Tests && dotnet test`
- Angular: `cd 17-desafio-angular-cypress && npm install && npm start` e em outro terminal `npm run test:e2e`
- Android: Android Studio e emulador; consulte 18-desafio-android-espresso.
