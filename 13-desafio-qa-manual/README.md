# O Dia a Dia de um QA: A Prática de Testes Manuais Funcionais

Entrega demonstrativa original para e-commerce fictício **Loja Exemplo**. Contém planejamento, histórias de usuário, fluxo de trabalho, mapa mental, casos, BDD, rastreabilidade e modelo de evidências. Nenhuma execução real foi alegada.

## Fluxo sugerido no Jira
Backlog → Refinamento → Pronto para desenvolvimento → Em desenvolvimento → Em teste → Concluído; bugs reabertos retornam ao desenvolvimento.

## Confluence
Crie páginas para escopo, critérios de aceite, estratégia, matriz de rastreabilidade e relatório de execução. Exporte evidências apenas após testes reais.
