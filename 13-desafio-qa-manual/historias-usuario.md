# Histórias de usuário

**US01** Como comprador, quero autenticar-me para acessar minha conta.
Critérios: usuário válido entra; senha incorreta apresenta erro; campos obrigatórios não permitem envio vazio.

**US02** Como comprador, quero adicionar itens ao carrinho para finalizar compras.
Critérios: quantidade e subtotal corretos; exclusão atualiza total; carrinho vazio exibe estado apropriado.

**US03** Como comprador, quero concluir pedido com endereço válido.
Critérios: campos obrigatórios validados; pedido gera confirmação; não permite checkout com carrinho vazio.
