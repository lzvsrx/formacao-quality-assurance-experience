# Criando seu Primeiro Repositório no GitHub Para Compartilhar Seu Progresso

Entrega original: repositório de estudos de QA, com README, .gitignore, projetos e histórico Git.

```bash
git init
git branch -M main
git add .
git commit -m "docs: inicia portfolio de QA"
git remote add origin https://github.com/SEU_USUARIO/formacao-quality-assurance-experience.git
git push -u origin main
```

Crie o repositório vazio antes de executar. Substitua SEU_USUARIO. Não envie credenciais.

- [ ] README com apresentação e objetivos
- [ ] .gitignore e licença escolhida conscientemente
